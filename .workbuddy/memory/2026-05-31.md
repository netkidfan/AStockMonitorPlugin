## buildPlugin 报错修复

修复了 `gradlew buildPlugin` 的两个问题：
1. **`UiDslException`（SEVERE）**：`StockMonitorConfigurable.kt` 第 133、144 行的 `.comment()` 传入了 `<html>...</html>` 包裹的字符串，新版 UI DSL 禁止手动加 `<html>` 标签，去掉外层标签即可。
2. **`InvalidPathException`（致命，导致 buildSearchableOptions FAILED）**：IDEA 内置 Gradle 插件在 headless 沙箱中从系统 PATH 读取 JDK 路径时，将 `\b` 当作退格符转义（路径变成 `jdk-17bin`），这是 IDEA 平台 bug 与项目代码无关。通过在 `build.gradle.kts` 中禁用 `buildSearchableOptions` 任务绕过，不影响插件功能。

### 踩过的坑（本次新增经验）

1. **Platform Plugin 2.16.0 要求 Gradle ≥ 9.0**（旧版 8.x 直接失败）
2. **IDEA 2025.3 起 Community 版与 Ultimate 版合并**，`intellijIdeaCommunity()` 不再可用，必须改为 `intellijIdea()`
3. **Kotlin 编译器版本须 ≥ 平台内置 Kotlin**：IDEA 2026.1.2 内置 Kotlin 2.3.0，编译器 2.1.x 无法读取元数据，需升级到 2.3.21
4. **UI DSL 依赖**：`com.intellij.ui.dsl.builder.*` 依赖 Kotlin 插件，需添加 `bundledPlugin("org.jetbrains.kotlin")`
5. **系统只有 JDK 17**：需在 `gradle.properties` 中显式配置 `org.gradle.java.home` + build.gradle.kts 中 `jvmToolchain(17)` 双重固定，防止 Platform Plugin 自动探测 JDK 21 失败
